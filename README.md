# 🏟️ התראות תנועה לאצטדיון טדי

אוטומציה ב-[n8n](https://n8n.io) ששולחת **התראה בטלגרם (ומייל)** לפני כל משחק
באצטדיון טדי בירושלים — כדי לדעת מתי לצאת בזמן מהעבודה ולהימנע מהפקקים סביב המגרש.

> נבנה במקור עבור צורך אישי: לדעת מראש על משחקים של **ביתר ירושלים** ו**הפועל ירושלים**
> בטדי, ולקבל המלצה מתי לתפוס רכבת מתל אביב או לצאת ברכב.

---

## ✨ מה זה עושה

בכל הרצה ה-workflow:

1. **בודק חגים** מול [Hebcal](https://www.hebcal.com) — ואם היום חג (יום טוב) הוא **לא שולח** התראות.
2. **מושך תחזית מזג אוויר** ל-14 יום קדימה מ-[Open-Meteo](https://open-meteo.com) (טמפ' + סיכוי גשם).
3. **אוסף משחקים בטדי** משלושה מקורות במקביל:
   - דף הקבוצה של **ביתר ירושלים** ב-sport5
   - דף הקבוצה של **הפועל ירושלים** ב-sport5
   - **API-Football** לפי `venue=866` (אצטדיון טדי) — תופס *כל* משחק במגרש, כולל גביע וקבוצות אחרות.
4. **מסנן ומאחד** את המשחקים (הסרת כפילויות לפי תאריך+שעה), ומשאיר רק משחקים עתידיים.
5. **מחשב לכל משחק** רמת דחיפות (🟢/🟠/🔴), והאם להגיע ברכבת או ברכב:
   - בימי חול → המלצת **רכבת מתל אביב** + שעת יציאה מהעבודה.
   - בשבת / ערב שבת / חג (רכבת ישראל לא פעילה) → המלצת **רכב** + שעת יציאה.
6. **שולח** הודעת טלגרם מעוצבת + מייל HTML, עם קישור ניווט ב-Waze לטדי.

## ⏰ תזמון

ה-Schedule Trigger רץ לפי שני ביטויי cron (אזור זמן של שרת ה-n8n):

| Cron | מתי | למה |
|------|------|-----|
| `0 8 * * 0-5`  | כל יום א׳–ו׳ ב-08:00 | סריקה יומית בוקר |
| `30 22 * * 6`  | מוצ״ש ב-22:30 | רענון אחרי צאת שבת |

## 🚀 התקנה

> דרישה מוקדמת: מופע n8n פעיל (ענן או self-hosted).

1. **ייבא את ה-workflow**: ב-n8n → *Workflows* → *Import from File* → בחר את
   [`workflow/teddy-stadium-alerts.json`](workflow/teddy-stadium-alerts.json).

2. **צור credentials** (ב-n8n UI, לא בקובץ):

   | Credential | סוג | שימוש |
   |------------|------|--------|
   | API-Football | **Header Auth** — שם הכותרת `x-apisports-key`, הערך = מפתח ה-API שלך מ-[api-football.com](https://www.api-football.com) | node `API-Football טדי` |
   | Telegram Bot | **Telegram API** — bot token מ-[@BotFather](https://t.me/BotFather) | node `Send a text message` |
   | Gmail | **Gmail OAuth2** | node `Send a message` (אופציונלי) |

3. **עדכן ערכים אישיים** (ראה [`.env.example`](.env.example) לרשימה המלאה):
   - `chatId` בנוד הטלגרם → ה-Chat ID האישי שלך (השג מ-[@userinfobot](https://t.me/userinfobot)).
   - `sendTo` בנוד ה-Gmail → כתובת המייל שלך.

4. **התאם פרמטרים אישיים** בנוד `חישוב משחקים עתידיים` במידת הצורך
   (זמני נסיעה — ראה למטה).

5. **הפעל** את ה-workflow (Active).

## ⚙️ פרמטרים שכדאי להתאים אישית

בנוד `חישוב משחקים עתידיים` (קוד JS):

| משתנה | ברירת מחדל | משמעות |
|--------|------------|---------|
| `TRAFFIC_START_HOURS` | `3.5` | כמה שעות לפני שריקת הפתיחה מתחיל העומס |
| `SAFETY_BUFFER_MIN` | `30` | מרווח ביטחון בדקות |
| `WALK_MIN` | `15` | הליכה מהעבודה לתחנת הרכבת |
| `TRAIN_MIN` | `50` | משך נסיעת הרכבת (ת״א → ירושלים) |
| `BUS_MIN` | `30` | משך הנסיעה מהתחנה בירושלים לטדי |

> ערכי המיקום (`latitude`/`longitude`, קואורדינטות Waze) מצביעים על אצטדיון טדי
> בירושלים ומשותפים לכולם — אין צורך לשנותם.

## 🔐 אבטחה ופרטיות

הקובץ שבריפו זה **עבר ניקוי** ואינו מכיל מידע אישי או סודות:
